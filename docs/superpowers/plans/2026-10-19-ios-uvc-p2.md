# iOS UVC P2: HID Control Sink

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Expose the existing ESP32 HID + `SessionTapController` path as a standard async `ControlSink`, so core orchestration can call it without platform branches.

**Spec:** `docs/ios-uvc-execution-plan.md` Phase P2

## Constraints

- Relative HID only; `supports_absolute_tap=False` even though the API takes an absolute target.
- `tap_abs` must call `SessionTapController.tap`, preserving pointer precheck.
- No hardware tests in this slice.
- Run blocking HID work off the event loop with `asyncio.to_thread`.

### Task 1: HidControlSink

**Files:** Create `artemis/control/hid.py`; test `tests/unit/control/test_hid_sink.py`.

**Interfaces:**
- `HidControlSink(session, controller)`.
- `capabilities = CapabilitySet(supports_relative_pointer=True, requires_pointer_precheck=True, supports_text_input=True)`.
- `async tap_abs(x,y) -> ActionResult`: `controller.tap(x,y)` in a thread; `ok=False` maps to incident `"no_effect"` and copies `result.message`.
- `async tap_rel(dx,dy) -> ActionResult`: `session.move(dx,dy)` in a thread.
- `async input_text(text)`, `async press_key(key)`.
- `async swipe(...)` uses `session.control.mouse_down/move/up` in a thread.
