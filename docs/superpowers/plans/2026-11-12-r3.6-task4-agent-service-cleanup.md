# R3.6 Task 4 — Agent Service Cleanup Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Flash and Validator use only the L3 `ActionService`/`ActionDispatchPort`, remove the execute-shaped `ActionExecutionPort` from the production type path, and keep helper tools on an explicit compatibility port.

**Architecture:** `ActionService` becomes command-port-first. Flash and Validator receive the service from context; helper tools use a separate `helper_port`. `get_action_service` is the primary accessor; `get_action_session` remains only a documented test/legacy alias. MCP remains an L1 adapter, not an Agent import.

**Tech Stack:** Python 3.12, pytest, Protocol/dataclasses, existing `ActionDispatchPort`, `McpActionPort`, `McpActionExecutor`.

**Spec:** `docs/superpowers/plans/2026-11-12-r3.6-task2-action-service-completion.md` and the Task 4 acceptance criteria.

## Global Constraints

- No `legacy_allowlist.py` entries.
- Production `artemis.agents.*` must not import `artemis.mcp`, `McpActionExecutor`, `ActionSession`, or Controller/Driver/Adapter modules.
- `ActionService` must not use an execute-shaped port for device actions.
- `ActionSession`/MCP are L1 concerns; only `McpActionPort` may touch them.
- Helper tools (`read_note`, `list_notes`, `ask_explorer`, `video_analyzer`, `play_reflex`, history) must remain available through an explicit helper boundary.
- Keep `get_action_session` importable as a compatibility alias during this task; do not make it the primary path.
- Every task is TDD: RED test, focused GREEN, commit.
- Do not add a new platform or change MCP tool schemas.

## Review Focus

- `ActionService` silently falling back to `port.execute` for a device action would preserve the old bypass.
- Validator tests patching `get_action_session` must be updated to the primary `get_action_service` target, or the test is not exercising the new path.
- Helper tools must not be routed into `DeviceActionService` just because they share `execute`.
- `ActionExecutionPort` remaining as a production constructor type means Task 4 is still partial.
- Full Agent transitive closure may still reach legacy tools→L4; record that as an explicit gap, not an allowlist.

        Path("artemis/agents/validator/validator.py"),
        Path("artemis/agents/validator/action_execution.py"),

            node.module
