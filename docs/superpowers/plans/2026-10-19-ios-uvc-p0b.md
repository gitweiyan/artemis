# iOS UVC P0b: DeviceSession and Driver Capabilities

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Compose perception sources and control sinks into a `DeviceSession`, and expose capability declarations on `BaseDeviceDriver` without changing existing behavior.

**Architecture:** `DeviceSession` aggregates capabilities, tries perception sources in order, and selects a control sink by capability (absolute first, relative fallback). `BaseDeviceDriver` gets a class-level `CapabilitySet`; Android declares its real capabilities.

**Tech Stack:** Python 3.12, pytest.

**Spec:** `docs/artemis-target-architecture.md`, `docs/ios-uvc-execution-plan.md`

## Global Constraints

- No iOS behavior in this slice.
- No change to existing abstract driver methods.
- Capabilities are declarations, not runtime feature detection.
- No hardware tests.

## Review Focus

- All sources failing must raise a typed error, not return the last frame.
- Absolute control must never silently fall back to relative when both are requested.
- Adding capability defaults must not change existing driver calls.

### Task 1: DeviceSession composition

**Files:**
- Create: `artemis/devices/session.py`
- Test: `tests/unit/devices/test_session.py`

**Interfaces:**
- Consumes: `PerceptionSource`, `ControlSink`, `CapabilitySet`, `Frame`, `ScreenGeometry`.
- Produces:
  - `DeviceSession(perception: list[PerceptionSource], control: list[ControlSink], geometry: ScreenGeometry)`.
  - `capabilities` property: union of all source/sink flags.
  - `async snapshot() -> Frame`: first source whose `health == "ok"`; continue on exception/bad health; raise `DeviceSessionError` if none.
  - `control_for(absolute: bool) -> ControlSink`: absolute → first `supports_absolute_tap`; relative → first `supports_relative_pointer`; raise `DeviceSessionError` otherwise.

- [ ] **Step 1: Write failing tests**

```python
class Source:
    def __init__(self, frame=None, error=None):
        self.capabilities = CapabilitySet(supports_ocr=True)
        self.frame, self.error = frame, error
    async def snapshot(self):
        if self.error: raise self.error
        return self.frame

class Sink:
    def __init__(self, absolute=False, relative=False):
        self.capabilities = CapabilitySet(
            supports_absolute_tap=absolute,
            supports_relative_pointer=relative,
            requires_pointer_precheck=relative,
        )

def test_snapshot_uses_first_healthy_source():
    bad = Frame(b"bad", 1.0, 10, 10, "bad", health="black")
    good = Frame(b"ok", 2.0, 10, 10, "good")
    session = DeviceSession([Source(bad), Source(good)], [], geometry)
    assert (await session.snapshot()).image == b"ok"

def test_all_sources_fail_with_typed_error():
    session = DeviceSession([Source(error=RuntimeError("x"))], [], geometry)
    with pytest.raises(DeviceSessionError):
        await session.snapshot()

def test_control_selection_is_capability_based():
    abs_sink, rel_sink = Sink(absolute=True), Sink(relative=True)
    session = DeviceSession([], [rel_sink, abs_sink], geometry)
    assert session.control_for(absolute=True) is abs_sink
    assert session.control_for(absolute=False) is rel_sink

def test_missing_control_raises():
    session = DeviceSession([], [], geometry)
    with pytest.raises(DeviceSessionError):
        session.control_for(absolute=False)
```
