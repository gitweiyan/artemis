# iOS UVC P0a: Capability Contracts and Geometry

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Introduce the platform-neutral capability, perception/control, and geometry contracts that the iOS UVC driver will compose.

**Architecture:** New `artemis/devices`, `artemis/perception`, and `artemis/control` packages. Dataclasses and `Protocol` interfaces only; no existing driver behavior changes. Coordinates stay normalized 0–1000 at the agent boundary; `ScreenGeometry` owns frame/content/screen conversions.

**Tech Stack:** Python 3.12, `dataclasses`, `typing.Protocol`, pytest.

**Spec:** `docs/artemis-target-architecture.md`, `docs/ios-uvc-execution-plan.md`

## Global Constraints

- No behavior change to `BaseDeviceDriver` or Android drivers in P0a.
- No platform-name branches in the new contracts.
- No UVC/HID implementation yet; contracts only.
- All coordinates use normalized 0–1000 at the agent boundary.
- Tests must not require hardware.

## Review Focus

- A source that lacks UI tree/OCR must advertise it, not return a fake empty success.
- Frame-to-screen conversion must reject invalid geometry rather than clamp silently.
- Protocol fakes must stand in for real sources/sinks without test-only production branches.

### Task 2: ScreenGeometry

**Files:**
- Create: `artemis/devices/geometry.py`
- Test: `tests/unit/devices/test_geometry.py`

**Interfaces:**
- Consumes: none.
- Produces:
  - `ScreenGeometry(frame_size: tuple[int,int], screen_size: tuple[int,int], content_rect: tuple[int,int,int,int] | None = None)`.
  - `content_rect` defaults to the full frame.
  - `frame_to_normalized(x,y) -> tuple[int,int]` (0–1000).
  - `normalized_to_screen(nx,ny) -> tuple[int,int]` (screen device pixels).
  - `normalized_to_frame(nx,ny) -> tuple[int,int]` (frame pixels).
  - Raises `ValueError` for non-positive sizes or a content rect outside the frame.

- [ ] **Step 1: Write the failing geometry tests**

import pytest
from artemis.devices.geometry import ScreenGeometry

def test_full_frame_maps_center_to_screen_center():
    g = ScreenGeometry((449, 974), (1080, 2400))
    assert g.frame_to_normalized(224, 487) == (499, 500)
    assert g.normalized_to_screen(500, 500) == (540, 1200)

def test_letterboxed_content_rect_is_honored():
    g = ScreenGeometry((1920, 1080), (1080, 2400), content_rect=(736, 53, 1185, 1027))
    assert g.normalized_to_frame(0, 0) == (736, 53)
    assert g.normalized_to_screen(1000, 1000) == (1080, 2400)
    assert g.frame_to_normalized(736, 53) == (0, 0)

def test_invalid_geometry_is_rejected():
    with pytest.raises(ValueError):
        ScreenGeometry((0, 100), (100, 100))
    with pytest.raises(ValueError):
        ScreenGeometry((100, 100), (100, 100), content_rect=(0, 0, 200, 100))
