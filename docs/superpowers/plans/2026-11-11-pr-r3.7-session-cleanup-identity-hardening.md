# PR-R3.7 Session Cleanup & Identity Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Make cancellation-safe Session cleanup observable and make UVC hardware identity unique within a host inventory instead of trusting a possibly duplicated USB serial.

**Architecture:** `DeviceSession.close()` treats adapter close tasks as protected work: outer cancellation is remembered but never cancels the closer. Leases are released only after every closer completes. `LeaseSet` returns a diagnostic report for residual locks. UVC identity resolution gets a host-scoped inventory view and falls back to port path when serials collide.

**Tech Stack:** Python 3.12, asyncio, pytest, dataclasses, existing `DeviceSession`/`LeaseSet`/`UVCIdentity`.

**Spec:** PR-R3.7 owner requirements; `docs/architecture/ARCHITECTURE_CONTRACT.md` §5.4/§6 and ADR-003.

## Global Constraints

- Scope: `artemis/devices/session.py`, `artemis/runtime/resource_lease.py`, `artemis/drivers/ios/uvc_identity.py`, `tests/unit/devices/test_session.py`, `tests/unit/core/test_canonical_identity.py`.
- Do not modify `config/artemis.jsonc`.
- Cancellation must still propagate to the caller, but only after adapter close and lease release.
- Never cancel an adapter close task because the outer task was cancelled.
- Lease release remains best-effort; residual locks are reported, not silently deleted.
- UVC serial uniqueness is **host-scoped**. Same serial on different hosts is not a collision.
- Duplicate serial within one host must fall back to `USB_PORT_PATH`; explicit config hints remain a lower-priority fallback.
- `strict=True` fails closed when no unique hardware identity exists.
- No Allowlist entries; no behavior changes outside these files.

## Review Focus

- Outer cancellation currently calls `task.cancel()` on the adapter closer; the acceptance test must prove the closer still reaches its end event before the lease event.
- A close task that ignores cancellation must not be forcibly abandoned; the Session may wait, but it must not release leases early.
- A Lease failure must include the resource id and residual-lock state; `CLOSED` must still be reached.
- A duplicate USB serial must not produce the same `uvc:host:serial` endpoint for two devices.
- Same serial on two hosts must remain valid and distinct by host.

```python
def test_cancelling_close_does_not_cancel_the_adapter_closer_before_leases():
    events: list[str] = []

    class SlowSink(Sink):
        async def aclose(self):
            events.append("adapter-start")
            await asyncio.sleep(0.05)
            events.append("adapter-end")

    class Leases:
        def release(self):
            events.append("leases")

    session = DeviceSession([], [SlowSink(absolute=True)], geometry(), leases=Leases())

    async def scenario():
        task = asyncio.create_task(session.close())
        await asyncio.sleep(0)
        task.cancel()
        with pytest.raises(asyncio.CancelledError):
            await task

    asyncio.run(scenario())

    assert events == ["adapter-start", "adapter-end", "leases"]
    assert session.state.value == "closed"
```

- [x] **Step 3: Implement cancellation-safe close**

In `DeviceSession.close()`:
- create the closer task once;
- on outer `CancelledError`, save it, call `uncancel()` where available, and keep waiting on `asyncio.shield(task)`;
- never call `task.cancel()` for an adapter close task;
- if the task raises a normal exception, record it and continue;
- after all closers, release leases;
- only after `_state = CLOSED`, re-raise the saved cancellation.

Do not use `asyncio.wait_for` or a timeout that can abandon the closer.

```python
def test_lease_release_reports_resource_id_and_residual_lock(tmp_path):
    class FakeLease:
        def __init__(self, resource_id, error=None):
            self.resource_id = resource_id
            self.error = error
            self.released = 0
            self.path = tmp_path / f"resource-{resource_id}.lock"

        def release(self):
            self.released += 1
            if self.error:
                raise self.error

    broken = FakeLease("uvc:host:one/capture", TypeError("bad closer"))
    healthy = FakeLease("serial:host:one/command")
    leases = LeaseSet(host_id="host", session_id="s", lease_dir=tmp_path)
    leases._leases = [broken, healthy]

    report = leases.release_with_report()

    assert report.released == ("serial:host:one/command",)
    assert report.errors[0][0] == "uvc:host:one/capture"
    assert "bad closer" in report.errors[0][1]
    assert report.residual == ("uvc:host:one/capture",)
```

## Task 3: Host-scoped UVC inventory and serial uniqueness

**Files:**
- Modify: `artemis/drivers/ios/uvc_identity.py`
- Test: `tests/unit/core/test_canonical_identity.py`

**Interfaces:**
- Produces `UsbEntry(product: str, serial: str | None, location_id: str | None)`.
- Produces `probe_usb_inventory(device_name, *, runner=None) -> tuple[UsbEntry, ...]`.
- `probe_usb_identity` remains a compatibility wrapper.
- `resolve_uvc_identity(..., host_id: str | None = None, inventory_probe=...)`.
- Resolution:
  1. matching entries with a serial unique within this host -> `HARDWARE_SERIAL`;
  2. otherwise a non-empty unique port path -> `USB_PORT_PATH`;
  3. otherwise explicit hint (non-strict) / error (strict);
  4. otherwise device-name hint.
- A serial appearing on more than one matching entry in one host is not usable as identity.

- [x] **Step 1: Write failing identity tests**

```python
def test_a_serial_is_stable_across_usb_ports():
    entries = (UsbEntry("USB Video", "SERIAL-1", "1-2.3"), UsbEntry("USB Video", "SERIAL-1", "1-2.4"))
    # one card was moved, not two cards; the caller supplies the observed serial
    # via probe, so this test uses a single matching entry per probe result
    assert resolve_uvc_identity("USB Video", host_id="host-a", inventory_probe=lambda _: entries[:1]).key == "SERIAL-1"


def test_duplicate_serial_falls_back_to_port_path():
    entries = (
        UsbEntry("USB Video", "DUP-1", "1-2.3"),
        UsbEntry("USB Video", "DUP-1", "1-2.4"),
    )
    first = resolve_uvc_identity("USB Video", host_id="host-a", inventory_probe=lambda _: entries)
    assert first.source is IdentitySource.USB_PORT_PATH
    assert first.key == "usb-1-2-3"


def test_same_serial_on_different_hosts_is_not_a_collision():
    entry = (UsbEntry("USB Video", "SERIAL-1", "1-2.3"),)
    a = resolve_uvc_identity("USB Video", host_id="host-a", inventory_probe=lambda _: entry)
    b = resolve_uvc_identity("USB Video", host_id="host-b", inventory_probe=lambda _: entry)
    assert a.key == b.key == "SERIAL-1"
    assert a.metadata["host_id"] == "host-a"
```
