# iOS UVC P1: UvcSource Snapshot

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Wrap the existing on-demand `UvcCapture` as a standard `PerceptionSource` with a single-frame snapshot and health classification.

**Architecture:** `UvcSource` calls the synchronous capture in a worker thread, decodes a downscaled sample, and reports `ok`/`black`/`decode_error`. UI tree/OCR/locate are explicitly unavailable; no stream and no HID.

**Spec:** `docs/ios-uvc-execution-plan.md` Phase P1

## Global Constraints

- One frame per `snapshot()`; no persistent ffmpeg.
- No HID/pointer code.
- `ui_tree`, `ocr`, `locate` return `None`, never fake data.
- Capture exceptions propagate; `DeviceSession` owns fallback.

### Task 1: UvcSource

**Files:** Create `artemis/perception/uvc.py`; test `tests/unit/perception/test_uvc_source.py`.

**Interfaces:**
- Produces `UvcSource(capture, *, name="uvc")` with `capabilities = CapabilitySet()`, async `snapshot() -> Frame`, async `ui_tree()/ocr()/locate()` returning `None`.
- `snapshot()` classifies a frame: `black` when mean brightness ≤ 2 or nonblack ratio ≤ 0.01; `decode_error` when PIL cannot decode; else `ok`.
