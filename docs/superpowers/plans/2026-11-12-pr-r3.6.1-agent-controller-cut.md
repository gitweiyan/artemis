# PR-R3.6.1 Agent → Controller Runtime Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove every runtime path by which an Agent holds or reaches a concrete Controller for observation, while keeping the action transport and legacy helper adapters compatible at L1.

**Scope:** `artemis/actions/service.py`, `artemis/mcp/action_port.py`, `artemis/mcp/action_transport.py`, `artemis/interfaces/action_bootstrap.py`, `artemis/agents/flash/runner.py`, `artemis/perception/observation.py`, plus the related tests and one new L1 message adapter.

**Baseline:** `integration/10101205-all-fixes` @ `aecc22d`; unit baseline `3885 passed / 5 skipped`; `quality_ratchet` 773 / 0 / 18.

## Why this is P0

The current graph is clean statically but still passes the legacy Controller at runtime:

```text
action_bootstrap
  -> McpActionExecutor (legacy helper, owns actuator.controller)
  -> McpActionTransport.controller
  -> McpActionPort.__getattr__("controller")
  -> ActionService.__getattr__("controller")
  -> FlashRunner.self.controller
  -> observe(ctx, self.controller) / capture_screenshot_and_parse_ui(...)
```

The architecture import graph cannot see this because the hand-off is duck-typed. The runtime bomb-controller test is therefore mandatory: it must prove the Agent never calls an object whose first attribute access raises.

## Non-negotiable semantics

- Agent code may use `ActionService` and `ObservationPort` only. It must not receive a Controller, Actuator, transport, or MCP session.
- `ActionService` has only explicit members: `ctx`, `port`, `helper_port`, `_device_service`, `action_tool_names`, `execute`, `close`. No passthrough for unknown names.
- `McpActionPort` has only explicit command/observation/helper methods. No passthrough for unknown names.
- `McpActionTransport` must not expose `controller`, `actuator.controller`, or any equivalent property.
- A present `DeviceSession` is authoritative. If it has no usable observation source or its snapshot fails, observation returns/raises failure; it never falls back to `ctx.controller`.
- Initial capture, post-action fallback capture, and normal observation all use the same `ObservationPort`.
- MCP tool schemas and `ToolExecutionResult` fields do not change.
- `langchain_core.messages.ToolMessage` is not imported by `artemis.actions`.

## Acceptance Matrix

| Requirement | Proof |
|---|---|
| No ActionService passthrough | `service.controller` raises `AttributeError`; source has no `__getattr__`/`__setattr__` |
| No McpActionPort passthrough | `port.controller` raises; source has no `__getattr__` |
| Transport does not expose Controller | `hasattr(transport, "controller") is False` |
| L1 injects Observation/Perception Port | bootstrap tests for Session and no-Session |
| Flash has no `self.controller` | constructor inspection + `assert not hasattr(runner, "controller")` |
| Initial/fallback/normal observation unified | one fake port receives all three calls |
| Session failure never falls back | `get_screen_data` with session + bomb controller raises Session error |
| Bomb controller untouched | runtime bomb test exercises all observation paths |
| Static/dynamic/transitive clean | architecture tests; no allowlist |
| LangChain conversion outside L3 | `actions/results.py` has no LangChain import; interface adapter test |
| No schema break | `ToolExecutionResult` fields and MCP tool schema unchanged |

## Rollback

Tasks 3–5 can be reverted independently. Task 1–2 are the contract cut: reverting them restores the old controller fallback and must not be mixed with the passthrough deletion. No database, firmware, or MCP wire schema migration is involved.

## Open Decisions to Confirm Before Execution

1. `ActionService` will not use `__slots__` (tests and dependency injection assign explicit members); “only explicit interface” means no attribute delegation, not prohibition of ordinary assignment.
2. `McpActionExecutor` remains the helper-port implementation for now; its internal `actuator.controller` is L1/legacy and is not exposed to Flash.
3. The interface function is named `to_langchain_tool_message(result)`; the old method is removed without a deprecated L3 wrapper.
