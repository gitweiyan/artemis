# ios-taobao — 淘宝/闪购 iOS 操作经验

适用于：iPhone 通过 UVC 看屏 + ESP32 HID 鼠标/键盘操作淘宝或闪购。

## 硬约束

- 先确认支付总价，而不是商品标价。
- 配送单杯低价商品常被“起送价”挡住。例：古茗单杯 ¥4.5，但起送 ¥22。
- 目标“支付 <10 元”时：
  1. 先扩大搜索/筛选，至少浏览多个店铺，记录每家的起送价、配送费、包装费；
  2. 不能只用当前可见的 3 家店就判断“配送模式无解”；
  3. 确实没有可行配送店时，才切“自取”；
  4. 不凑单超过预算。
- 结论纪律：区分“当前样本无解”和“全局无解”。写结论时必须说明样本范围。
- 支付/Face ID/密码必须由用户完成；自动化只到支付确认页。

## 机台操作（指针 / OCR / 点击）

这些不是淘宝专属规则，已收敛到唯一事实源：
**[`docs/ios-rig-playbook.md`](../../docs/ios-rig-playbook.md)**（触发索引、门禁、排障顺序、
点击落点、采集健康、沉淀规则）。动手前读它，并跑 `artemis ios-smoke`。

本文件只保留淘宝/闪购的业务约束（预算、起送价、结论纪律、下单前检查）。

## 下单前检查

```text
[ ] 商品是珍珠奶茶，不是相邻商品
[ ] 规格：默认/少冰/糖度已确认
[ ] 商品价 + 配送费 - 优惠 ≤10
[ ] 起送价满足
[ ] 优惠券已尽量领取
[ ] 地址正确
[ ] 商品卡由 OCR bbox 定位，未使用整图目测坐标
[ ] 滚动优先用键盘，未从屏幕底部上滑
[ ] 到支付确认页停止，等用户确认
```
